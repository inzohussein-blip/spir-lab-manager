# Spir Lab Manager — إدارة مختبر التحاليل الطبية

تطبيق احترافي موجّه بالكامل لإدارة مختبرات التحاليل الطبية، مبني بنفس مكدس
البرنامج المحاسبي [Spir-Margin](https://github.com/inzohussein-blip/Spir-Margin)
ليشاركه قاعدة بيانات واحدة لاحقاً.

- **الإطار:** Next.js 14 (App Router) + TypeScript
- **الواجهة:** Tailwind CSS v4 + Radix UI (عربي RTL)
- **قاعدة البيانات:** Postgres — PGlite مدمج محلياً / Supabase عبر `DATABASE_URL`
- **الاستضافة:** Vercel

> 📄 خطة المشروع الكاملة وتحليل الخيارات في [`docs/PROJECT_REFERENCE.md`](docs/PROJECT_REFERENCE.md).

## التشغيل محلياً (صفر إعداد)

```bash
npm install
npm run dev
```

يعمل التطبيق مباشرة على PGlite (Postgres مدمج) ويطبّق الهجرات والبيانات
التجريبية تلقائياً. الدخول: `admin` / `admin123`.

## النشر على Vercel + Supabase

1. أنشئ (أو استخدم) مشروع Supabase — نفس مشروع `Spir-Margin` للقاعدة المشتركة.
2. طبّق الهجرات تحت `supabase/migrations` على القاعدة.
3. اضبط متغيرات البيئة (انظر `.env.example`):
   - `DATABASE_URL` — سلسلة اتصال Postgres المستضاف.
   - `AUTH_SECRET` — نفس قيمة `Spir-Margin` لتسجيل دخول موحّد.
   - `ANTHROPIC_API_KEY` — للمساعد الذكي (اختياري).
